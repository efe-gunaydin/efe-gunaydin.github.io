Argo CD

A
Kısaca
Git repo'sundaki Kubernetes manifest'lerini izleyip cluster'ı otomatik o hâle getiren bir "senkronizasyoncu".
↓ Kurulum 📖 Dokümantasyon ⌥ GitHub

Bu Ne? GitOps Mantığı.

Geleneksel deploy: Jenkins build alır, sonra cluster'a kubectl apply ile bir şey gönderir. Sorun şu: cluster'ın gerçek hâli ile senin Git'teki yaml dosyaların eşleşmeyebilir. Birisi cluster'da manuel değişiklik yapmış olabilir, sen unutmuş olabilirsin.

GitOps der ki: "Cluster'ın olması gereken hâlinin tek ve gerçek kaynağı Git'tir." Argo CD de bu felsefenin polisi: sürekli Git'i izler ve cluster'ı Git'tekiyle senkronize tutar. Birisi cluster'da elle bir şey değiştirirse Argo CD ya bunu geri alır, ya da "drift var" diye uyarır.

Bir Argo CD Uygulaması Nasıl Tanımlanır?

# argocd-app.yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: order-service
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://github.com/myorg/k8s-manifests
    targetRevision: main
    path: order-service/overlays/prod
  destination:
    server: https://kubernetes.default.svc
    namespace: production
  syncPolicy:
    automated:
      prune: true       # git'ten silinen kaynaklar cluster'dan da silinsin
      selfHeal: true    # cluster manuel değişirse geri al

Bu YAML cluster'a uygulandığı an Argo CD o git repo'yu sahiplenir. Sen kubectl yazmazsın; bir şey değiştirmek istiyorsan Git'e PR açarsın.

Diğer Araçlarla İlişkisi

  • Jenkins / GitHub Actions: Hâlâ build/test ve image push yapar. Tek fark: artık deploy komutu vermezler. Onun yerine manifest repo'sundaki image tag'ini güncellerler. Argo CD geri kalanını yapar.
  • Helm / Kustomize: Manifest yazarken kullanılan template araçları. Argo CD ikisini de native destekler.
  • Kubernetes: Argo CD'nin koştuğu yer. K8s'siz Argo CD anlamsız.
  • Grafana / Prometheus: Deploy sonrası metric'ler Grafana'da. Hata oranı artarsa Argo Rollouts ile otomatik canary/rollback yapılabilir.
Stajyer notu
"GitOps" duyunca bunu hatırla: Git = tek kaynak, cluster = yansıma. Production'da bir şey bozulduysa ilk soracağın soru: "Git'te ne yazıyor?"
