Spring Boot → Telefon Ekranı

Backend'den dönen MessageBoxResponse'u gerçek zamanlı olarak telefon ekranında görselleştirir. Tıpkı GetirFinans'ta olduğu gibi — sen backend'i değiştirirsin, burada canlı görürsün.

// Kodda ne yazarsan sitede ne olur
screenType — nasıl görünsün
DRAWER Aşağıdan yukarı kayan panel. En yaygın kullanım.
FULLSCREEN Tam ekranı kaplar. Kapatılamaz hata mesajları için.
SMALLINAPPMESSAGE Üstten düşen pop-up banner. Kampanya, uyarı.
messageType — hangi ikonla
✕ ERROR Kırmızı — hata durumu
⚠ WARNING Sarı — uyarı
✓ SUCCESS Yeşil — başarı
i INFORMATION Mavi — bilgi
cancellable — kapatılabilir mi
true X butonu görünür, kullanıcı kapatabilir.
false X butonu yok, kullanıcı zorla aksiyon almalı. Kritik hatalar için.
backgroundColor — arka plan rengi
#5d3ebc Getir moru
#251A49 Koyu mor (slide-up)
#ffffff Beyaz (varsayılan)
items — bullet point listesi
Madde listesi göstermek için kullan. Her eleman ayrı bir bullet olarak render edilir. 
.items(List.of(
    "Birinci madde açıklaması",
    "İkinci madde açıklaması"
))
messageBoxAction → uiStyle — buton görünümü
Tamam
BUTTON
İptal
TEXT
Daha fazla
UNDERLINETEXT
// Mor FULLSCREEN → kodda böyle yaz
MessageBox.builder()
    .title("Öğrenci Eklendi")
    .subTitle("Ahmet başarıyla kaydedildi.")
    .messageType(MessageBoxType.SUCCESS)
    .screenType(MessageBoxScreenType.FULLSCREEN)  // tam ekran
    .cancellable(true)                            // X butonu görünsün
    .backgroundColor("#5d3ebc")                   // mor arka plan
    .messageBoxAction(List.of(
        MessageBoxAction.builder()
            .text("Tamam")
            .uiStyle("BUTTON")                    // dolu buton
            .actionType("NONE")
            .build(),
        MessageBoxAction.builder()
            .text("İptal")
            .uiStyle("TEXT")                      // sadece yazı
            .actionType("NONE")
            .build()
    ))
    .build();
// Nasıl Çalıştırılır
◆ Projeyi İndir
// Bu simülatörü denemek için student-api projesine ihtiyacın var 
git clone https://github.com/efe-gunaydin/student-api.git
cd student-api
./mvnw spring-boot:run
// Kaynak kod → github.com/efe-gunaydin/student-api ↗
01
PostgreSQL'i Docker ile başlat
Aşağıdaki komutu terminalde çalıştır. Bu komutu sadece bir kez yapman yeterli — Docker container'ı kapanmadan veri kalır. 
docker run --name student-db \
  -e POSTGRES_DB=student_db \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=1234 \
  -p 5432:5432 -d postgres
Container daha önce oluşturulmuşsa: docker start student-db
02
DBeaver ile bağlantıyı doğrula (opsiyonel)
DBeaver'ı aç → New Connection → PostgreSQL → localhost:5432, database: student_db, user: postgres, password: 1234. Bağlantı başarılıysa student tablosunu göreceksin.
03
IntelliJ'de student-api projesini çalıştır
StudentApiApplication.java'yı aç → Run. Spring Boot localhost:8080'de başlayacak. @CrossOrigin(origins = "*") annotation'ının StudentController'da olduğundan emin ol — yoksa tarayıcı isteği bloklar. 
@CrossOrigin(origins = "*")
@RestController
@RequestMapping("/api/students")
public class StudentController { ... }
04
Bu sayfayı tarayıcıda aç
VSCode'da Live Server ile ya da direkt dosyayı tarayıcıya sürükle. Aşağıdaki simulator, localhost:8080'e direkt istek atar. Postman'e gerek yok.
05
IntelliJ'de MessageBox parametrelerini değiştir, burada izle
StudentController.java'da messageType, screenType, cancellable gibi değerleri değiştir → Spring Boot'u restart et → Send bas → telefon ekranında değişimi gör. Tam GetirFinans mantığı: backend doldurur, frontend gösterir. 
// Bunu değiştirince telefon ekranı değişir:
MessageBox.builder()
    .title("Öğrenci Eklendi")
    .messageType(MessageBoxType.SUCCESS)   // ERROR, WARNING, INFORMATION
    .screenType(MessageBoxScreenType.DRAWER) // FULLSCREEN, SMALLINAPPMESSAGE
    .cancellable(true)
    .build();
// localhost:8080 çalışıyor olmalı
